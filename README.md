# svl-bridge

Server-side bridge mod for Sunveil Connect — Auto-Manifest & Heartbeat Sync.

Multi-loader support: Paper, Fabric, Forge, NeoForge.

## Build

```bash
./gradlew build      # Compile all loaders (Paper, Fabric, Forge, NeoForge)
```

Output JARs are located in each submodule's `build/libs/` directory.
